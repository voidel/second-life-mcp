# Reference data attribution

Application source code is licensed under [MIT](LICENSE).

The independently written reference summaries, caveats and guidance in
`src/second_life_mcp/data/` are provided under
[Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
They paraphrase source material; the source_url field identifies the relevant
page or definition. Signatures identify API facts, not implementations.

Sources include the Second Life Wiki contributors and Linden Lab's creation
documentation. Each entry records its manual review date. The summaries are
abbreviated and rewritten; consult the original for full behavior and examples.
No example script implementations from these sources are bundled.

Some SLua signatures were checked against Linden Lab's MIT-licensed
[sl-vscode-plugin definitions](https://github.com/secondlife/sl-vscode-plugin/blob/5769f7cb07ada04f58206782a3f80a8f82102b3d/data/dev/sl-lua-defs.json).
